# Code of Conduct

Be direct, but do not be a jerk.

This project is small. The best way to keep it useful is to make issues and PRs easy to read, easy to test, and easy to discuss.

## Expected behavior

Please:

```txt
stay on topic
explain the concrete problem
criticize code, not people
assume mistakes are fixable
keep PR comments specific
give enough detail for someone else to reproduce the issue
```

Good issue:

```txt
Recall@5 is wrong when a query has two relevant docs and only one appears in the top 5.
Here is the golden row, run row, expected value, and actual value.
```

Bad issue:

```txt
This is broken.
```

## Unacceptable behavior

Do not use this project for:

```txt
harassment
threats
personal attacks
spam
sexual or hateful comments
doxxing
posting private information
derailing every thread into unrelated arguments
```

## Enforcement

Maintainers may edit, hide, or delete comments that make the project harder to work on.

Maintainers may close issues or PRs that are abusive, spammy, or not actionable.

Maintainers may block people who keep creating problems after being asked to stop.
